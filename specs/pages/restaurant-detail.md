# 식당 상세 페이지 (Restaurant Detail Page) 구현 계획

## 1. 개요

- **목적**: 특정 식당의 정보, 공지사항을 확인하고 관련된 리뷰 리스트를 보거나 새 리뷰를 작성.

## 2. 레이아웃 및 컴포넌트

- **Place Header Image / Info**:
  - 상단 배경 이미지 (리뷰 이미지 중 대표 사진 또는 카카오맵 로드뷰/썸네일 활용).
  - 식당 기본 정보: 상호명, 카테고리(카페/식당), 평균 별점, 자체 리뷰 수.
  - 북마크 버튼 (클릭 시 맛집 그룹 추가 플로우).
- **Tab Navigation**:
  - `식당 정보`, `상세 정보`, `식당 리뷰` 3개의 탭.
- **Tab Content - 식당 정보**:
  - 주소 텍스트 및 복사 버튼.
  - 한 줄 소개.
  - 카카오맵 API 기반 미니 지도 (위치 확인용).
- **Tab Content - 상세 정보**:
  - 운영시간, 식당 측 공지사항 (메뉴 제외).
- **Tab Content - 식당 리뷰**:
  - '리뷰 작성하기' 버튼 (버튼 형태 또는 Floating Action Button).
  - 해당 식당에 작성된 리뷰 피드 카드 리스트 (무한 스크롤 지원).

## 3. 상태 관리

- **Local State**:
  - 현재 활성화된 탭 상태 관리 (`activeTab`).
  - 북마크 클릭 시 '그룹 선택 바텀 시트(Bottom Sheet)' 렌더링 여부.
- **Server State**:
  - 식당 기본 정보 및 메타 데이터.
  - 식당 리뷰 리스트 페이징 데이터.

## 4. API 연동

- `GET /api/places/{id}` (카카오맵 장소 데이터 및 서버 메타데이터 조합)
- `GET /api/places/{id}/reviews` (리뷰 목록 커서 기반 페이징)
- `POST /api/places/{id}/bookmark` (내 맛집 그룹에 추가/제거)
- `POST /api/reviews` (리뷰 작성 - 해당 식당 ID 맵핑)

## 5. 주요 인터랙션

- **맛집 저장**: 북마크 아이콘 클릭 시 하단에서 바텀 시트가 올라와 내 그룹 목록을 보여주고 다중 선택 가능하도록 구현.
- **리뷰 작성 플로우**: 리뷰 작성 버튼 클릭 시 사진 다중 업로드, 별점 입력, 텍스트 입력이 가능한 '리뷰 작성 페이지/모달'로 이동 (영수증 인증 플로우 추후 고려).
