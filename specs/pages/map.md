# 지도 페이지 (Map Page) 구현 계획

## 1. 개요

- **목적**: 내 맛집, 그룹별 맛집, 팔로워의 맛집을 지도 상에서 시각적으로 탐색하고 접근.

## 2. 레이아웃 및 컴포넌트

- **전역 사이드바 숨김**:
  - `App.vue`에서 전역 `RootSidebar`를 렌더링하지 않고, 지도 화면에 최적화된 화면 구성을 사용.
- **Map View (카카오맵 SDK 연동)**:
  - 남은 화면 영역(`flex-1`)을 꽉 채우는 지도 컴포넌트.
  - 중심 좌표(Center) 변경 시 이벤트를 방출하여 현재 위치 추적.
- **MapSidebar (좌측 고정 사이드바)**:
  - 플로팅 형태가 아닌 지도와 공간을 분할하는 Flex 구조의 고정형 사이드바.
  - 상단: 장소/식당 검색 입력 폼 (키워드 입력).
  - 중단: 카카오 장소 검색 API를 활용한 거리순 검색 결과 리스트.
  - 하단: (기존 기획과 달리 유저 인증 버튼은 제외, 검색 집중형).
- **Floating Area**:
  - 우측 상단에 홈페이지(`/`)로 돌아가는 뒤로가기 원형 버튼.
- **Place Info Bottom Sheet**:
  - 지도 마커 클릭 시 하단에서 나타나는 식당 요약 카드 컴포넌트 (상호명, 주소, 카테고리, 폰번호). 클릭 시 상세 이동.

## 3. 상태 관리

- **Local State**:
  - 지도의 현재 중심 좌표(Center Lat/Lng) 및 이동 시 동적으로 갱신되는 뷰 중심 좌표.
  - 사이드바 내 검색어 입력 상태 및 검색 결과(searchResults).
  - 현재 클릭/활성화된 마커(`selectedPlace`)의 정보.
  - 지도에 렌더링해야 할 '필터링된 맛집 목록(마커 핀)'.
- **Server State**:
  - 렌더링에 필요한 맛집 마커 좌표 및 기본 정보 배열.

## 4. API 연동

- **카카오 장소 검색 API (`window.kakao.maps.services.Places`)**:
  - 키워드 검색 시 음식점(`FD6`)과 카페(`CE7`) 카테고리 코드를 적용하여 2회 병렬 동시 호출.
  - `location` 및 `sort` 옵션을 사용하여 현재 지도 중심 좌표 기반 거리순(`SortBy.DISTANCE`) 검색 적용.
- (추후 연동) `GET /api/groups/me` (내 맛집 그룹 리스트) 등 기존 그룹 조회 기획.

## 5. 주요 인터랙션

- 지도를 드래그하여 이동을 멈출 때마다(`idle`), 중심 좌표가 갱신되며 검색 시 **현재 화면에서 가까운 순서**로 식당/카페가 나타남.
- 사이드바 검색 폼에서 장소 검색 시 카카오 API를 통해 결과를 가져오고, 두 카테고리(식당, 카페) 결과를 혼합하여 거리순으로 자동 재정렬(`sort`) 수행.
- 검색 결과 클릭 시 해당 위치로 지도가 부드럽게 패닝(Panning)되며 중심 이동, 동시에 하단 Bottom Sheet 노출 및 마커 포커스.
