# 지도 페이지 (Map Page) 구현 계획

## 1. 개요
- **목적**: 내 맛집, 그룹별 맛집, 팔로워의 맛집을 지도 상에서 시각적으로 탐색하고 접근.

## 2. 레이아웃 및 컴포넌트
- **Map View (카카오맵 SDK 연동)**:
  - 화면 전체(Full-screen)를 채우는 지도 컴포넌트.
  - 커스텀 마커 렌더링 로직 (그룹별 혹은 유저별 마커 아이콘 차별화 옵션).
- **Floating Area**:
  - 최상단 검색창 모사 UI (클릭 시 사이드바의 검색 탭 오픈).
  - 내 위치로 이동(Geolocation) 플로팅 버튼.
  - 사이드바 메뉴 호출 버튼(햄버거 아이콘 등).
- **Sidebar (Drawer 형태)**:
  - **식당 검색 탭**: `SearchBar`, 식당 리스트 결과, 북마크 저장 기능.
  - **팔로워 맛집 탭**: 팔로워 목록 아코디언 UI -> 펼치면 유저의 그룹 리스트.
  - **맛집 그룹 보기 탭**: 내 그룹 리스트. 그룹 관리(추가/수정/삭제).
- **Place Info Bottom Sheet**:
  - 지도 마커 클릭 시 하단에서 나타나는 식당 요약 카드 컴포넌트 (상호명, 주소, 카테고리, 평점). 클릭 시 상세 이동.

## 3. 상태 관리
- **Local State**: 
  - 지도의 현재 중심 좌표(Center Lat/Lng) 및 줌(Zoom) 레벨.
  - 현재 클릭/활성화된 마커의 정보.
  - Drawer 사이드바의 열림/닫힘 상태 및 선택된 탭 정보.
  - 지도에 렌더링해야 할 '필터링된 맛집 목록(마커 핀)'.
- **Server State**: 
  - 렌더링에 필요한 맛집 마커 좌표 및 기본 정보 배열.

## 4. API 연동
- 카카오맵 웹 API (지도 JS API 직접 활용 또는 vue3-kakao-maps 등 Vue 생태계 라이브러리 활용).
- `GET /api/groups/me` (내 맛집 그룹 리스트)
- `GET /api/groups/{groupId}/places` (특정 그룹 내 식당 목록)
- `GET /api/users/follows` (팔로워 목록 조회)

## 5. 주요 인터랙션
- 마커 클릭 시 해당 위치로 지도가 부드럽게 패닝(Panning)되며 중심 이동, 동시에 하단 Bottom Sheet 노출.
- 사이드바에서 특정 유저나 그룹을 선택할 경우, 기존 마커들을 클리어하고 선택된 데이터셋의 마커들만 새롭게 지도에 뿌리도록 상태 갱신.
