# 유저 페이지 (User Page) 구현 계획

## 1. 개요

- **목적**: 특정 유저(또는 나)의 프로필 정보, 작성한 리뷰, 저장한 맛집 그룹을 모아보는 공간.

## 2. 레이아웃 및 컴포넌트

- **Top Header**:
  - 좌측: 뒤로가기
  - 중앙: 유저 핸들 (@id)
  - 우측: (내 페이지인 경우) 설정(톱니바퀴) 아이콘
- **Profile Section**:
  - 프로필 이미지(아바타), 닉네임, 이메일, 한 줄 소개(Bio).
  - 팔로워 수, 팔로잉 수 (클릭 가능 영역).
  - 버튼 영역: 타인 페이지일 경우 [팔로우/언팔로우], 내 페이지일 경우 [프로필 편집].
- **Tab Navigation**:
  - `리뷰 피드` 탭 / `맛집 그룹` 탭
- **Tab Content - 리뷰 피드**:
  - 인스타그램의 개인 페이지처럼 그리드 형태로 사진 썸네일 배치 (또는 피드 카드 리스트).
  - 무한 스크롤 적용.
- **Tab Content - 맛집 그룹**:
  - 유저가 보유한 그룹 목록을 카드 리스트 형태로 렌더링.
  - `모든 맛집 보기` 그룹은 삭제 불가하며 최상단 배치.
  - 내 페이지일 경우 새로운 그룹을 생성할 수 있는 '+' 영역 제공.

## 3. 상태 관리

- **Server State**:
  - 접속한 페이지 대상의 유저 프로필 데이터.
  - 유저가 작성한 리뷰 목록 데이터.
  - 유저가 소유한 그룹 목록 데이터.
- **Local State**:
  - 선택된 탭 (`리뷰 피드` / `맛집 그룹`).
  - 팔로워/팔로잉 명단 모달 토글 상태.

## 4. API 연동

- `GET /api/users/{handle}` (유저 프로필 조회)
- `GET /api/users/{handle}/reviews` (작성 리뷰 목록 페이징)
- `GET /api/users/{handle}/groups` (맛집 그룹 목록)
- `POST /api/follows/{userId}` (팔로우 상태 토글)

## 5. 주요 인터랙션

- 팔로워 혹은 팔로잉 카운트 영역 클릭 시 명단(이미지, 이름, 핸들 포함)을 바텀 시트 또는 전체 화면 모달로 제공.
- 그룹 썸네일 클릭 시 해당 그룹에 속한 맛집들 리스트(또는 지도 뷰)로 라우팅.
