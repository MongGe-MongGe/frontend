# 인증 및 설정 페이지 구현 계획

## 1. 인증 페이지 (Auth View)

### 레이아웃 및 컴포넌트

- **Login Component**:
  - 로고 영역.
  - 이메일/비밀번호 입력 폼 (`Input` 컴포넌트).
  - 아이디 저장 체크박스, 로그인 버튼.
  - 간편 소셜 로그인 버튼 리스트 (네이버, 카카오, 구글 등).
  - '비밀번호 찾기' 및 '회원가입' 링크.
- **Sign Up Component**:
  - 단계별 입력 또는 단일 긴 폼 형태.
  - 닉네임, 이메일, 전화번호, 아이디(@handle), 비밀번호, 비밀번호 확인.
  - 유효성 검사 결과 에러 텍스트 컴포넌트.

### 기능 및 상태 관리

- VeeValidate 또는 커스텀 컴포저블(Composables)과 Zod 등을 이용한 클라이언트 사이드 폼 검증 로직 구현 권장.
- 로그인 성공 시 서버로부터 받은 JWT 토큰(또는 세션 정보)을 브라우저 스토리지 및 글로벌 상태(Pinia)에 저장.
- **전역 라우팅 가드 (`router.beforeEach`)**:
  - 앱 전역에 네비게이션 가드를 설정하여, **로그인되지 않은 유저는 인증 페이지(`/login`, `/signup`) 외의 모든 페이지 접근을 차단**하고 로그인 화면으로 리다이렉트시킴.
  - 역으로 로그인된 유저는 `/login`, `/signup` 접근 시 즉시 메인 피드(`/`)로 리다이렉트 처리.

### API 연동

- `POST /api/auth/login` (로그인)
- `POST /api/auth/register` (회원가입)
- `GET /api/auth/check-handle` (핸들 중복 체크)

## 2. 설정 페이지 (Settings View)

### 레이아웃 및 컴포넌트

- 인스타그램/페이스북 앱의 설정 화면을 벤치마킹하여 리스트 뷰 구조 구성.
- 각 기능이 명확히 설명된 셀(Cell) 리스트 형태.
- **내 정보 수정 섹션**:
  - 프로필 이미지 업로드 및 미리보기.
  - 닉네임, 한줄 소개 수정.
- **계정 관리 섹션**:
  - 로그아웃 버튼.
  - 회원 탈퇴 버튼 (경고 텍스트 포함).

### 기능 및 API

- 프로필 이미지 업로드 시 브라우저 내 미리보기 처리(`URL.createObjectURL` 또는 `FileReader`) 후 폼 데이터로 서버 전송.
- 로그아웃 처리 및 전역 상태 초기화, 로컬/세션 스토리지 클리어 후 렌딩 페이지 리다이렉트.
- 탈퇴 시 실수 방지를 위한 2차 확인 모달(재확인 입력 폼 등) 제공 필수.
- `PUT /api/users/me` (정보 수정), `POST /api/auth/logout`, `DELETE /api/users/me`.
