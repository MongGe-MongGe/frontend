# 메인 페이지 (Main Page) 구현 계획

## 1. 개요
- **목적**: 다른 유저들이 작성한 맛집 리뷰 피드를 탐색하는 공간.
- **특징**: 인스타그램과 유사한 세로 스크롤 형태의 무한 스크롤 구현.

## 2. 레이아웃 및 컴포넌트
- **GNB**: 로고, 검색 아이콘, 알림 아이콘, 프로필 아이콘 등.
- **FeedList Component**:
  - `FeedCard` 컴포넌트의 리스트 렌더링.
  - 무한 스크롤 트리거 역할을 하는 `IntersectionObserver` 요소 (또는 관련 라이브러리 활용).
- **FeedCard Component**:
  - 작성자 프로필 (이미지, 닉네임, 핸들, 팔로우 버튼)
  - 식당 정보 및 이미지 슬라이더 (Carousel)
  - 리뷰 내용 (더보기/접기 기능)
  - 상호작용 버튼 영역 (좋아요, 댓글, 공유하기)
  - 작성일, 좋아요 수 등 메타 데이터 표시

## 3. 상태 관리 (State)
- **Server State**: 
  - Pinia 및 Axios를 활용한 피드 데이터 페칭 및 관리 (커서 기반 무한 스크롤 상태 유지).
- **Local State**:
  - 개별 피드의 좋아요 상태 (Optimistic UI 업데이트 적용).
  - 텍스트 더보기/접기 토글 상태.

## 4. API 연동
- `GET /api/feeds` (cursor-based pagination 기반의 리뷰 목록 조회)
- `POST /api/reviews/{id}/like` (좋아요 토글)
- `POST /api/follows/{userId}` (작성자 팔로우 토글)

## 5. 주요 인터랙션
- 피드 하단 도달 시 추가 데이터 자동 로드(무한 스크롤).
- 좋아요 하트 클릭 시 마이크로 애니메이션 제공.
- 식당 정보 클릭 시 `식당 상세 페이지`로 이동.
- 작성자 프로필 클릭 시 `유저 페이지`로 이동.
