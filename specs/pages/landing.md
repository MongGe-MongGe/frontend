# 렌딩 페이지 (Landing Page) 구현 계획

## 1. 개요

- **목적**: 서비스(구루밍)의 정체성을 소개하고 회원가입/로그인으로 유도.
- **특징**: 모바일 중심의 반응형 레이아웃, 부드러운 인터랙션.

## 2. 레이아웃 및 컴포넌트

- **GNB (Global Navigation Bar)**:
  - 로고 (좌측)
  - '로그인하기' 버튼 (우측)
- **Hero Section**:
  - 메인 카피: "나만의 맛집을 기록하고 공유하세요, 구루밍"
  - 서비스 소개 이미지/목업 (애니메이션 효과 적용)
  - CTA 버튼 ('시작하기' 또는 '로그인하기')
- **Feature Section**:
  - 지도 기반 맛집 저장 소개
  - SNS 형태의 피드 및 리뷰 공유 소개

## 3. 상태 관리 (State)

- **Local State**: 스크롤 위치 (헤더 배경색 변경 등 애니메이션 용도)
- **Global State**: 사용자 로그인 여부 (로그인되어 있을 경우 메인 페이지로 리다이렉트)

## 4. API 연동

- 본 페이지 자체는 정적 데이터 위주이므로 특별한 데이터 페칭 API는 불필요.

## 5. 주요 인터랙션

- 첫 진입 시 페이드인(Fade-in) 애니메이션.
- 스크롤에 따른 요소 등장(Scroll Reveal) 애니메이션.
- CTA 버튼 클릭 시 로그인/회원가입 모달 또는 페이지로 이동.
