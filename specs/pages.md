# 페이지별 스펙 (Page Specifications)

이 파일은 각 페이지별 상세 구현 계획을 담기 위해 `/pages/` 디렉토리 하위의 개별 파일들로 분할되었습니다.
각 페이지별 세부 계획은 아래 파일들을 참조해 주세요.

- `frontend/specs/pages/landing.md` : 렌딩 페이지
- `frontend/specs/pages/main.md` : 메인 페이지 (피드)
- `frontend/specs/pages/explore.md` : 탐색 페이지 (검색 및 이벤트)
- `frontend/specs/pages/review-detail.md` : 리뷰 상세 페이지
- `frontend/specs/pages/restaurant-detail.md` : 식당 상세 페이지
- `frontend/specs/pages/map.md` : 지도 페이지
- `frontend/specs/pages/user.md` : 유저 프로필 페이지
- `frontend/specs/pages/notice.md` : 공지사항 및 이벤트 페이지
- `frontend/specs/pages/auth-and-settings.md` : 인증(로그인/회원가입) 및 환경설정 페이지
