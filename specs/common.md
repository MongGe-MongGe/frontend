# 공통 스펙 (Common Specifications)

## 1. 서비스 개요

- **서비스 명**: 구루밍 (Gourming)
  - '구르메(Gourmet)' + 'ing'의 합성어.
  - 구름이라는 느낌과 고양이가 구루밍 하듯 맛을 본다는 의미를 내포.
- **주요 기능**: 음식점 및 카페를 저장하기 위한 지도 기능과 내 맛집 지도 혹은 리뷰를 공유하기 위한 SNS 기능을 결합한 서비스.
- **서비스 지향점**:
  - 간단하고 직관적인 리뷰 작성을 강조하여 사용자가 쉽게 즐길 수 있도록 설계.
  - 복잡한 기능과 디자인은 최대한 배제.
  - **레이아웃 정책**: 반응형 디자인(미디어 쿼리 등)을 배제하고 데스크톱에서도 모바일 앱과 동일한 화면 형태(최대 너비가 제한된 중앙 컨테이너)를 제공하여 일관된 뷰를 구성. 지도를 제외한 모든 페이지는 이 컨테이너 안에 렌더링.
  - **사이드 네비게이션**: 상단 헤더와 하단 탭을 통합한 토글형 좌측 사이드바(사이드 네비게이션) 구조를 사용하여 y축 스크롤 시야를 넓게 확보.

## 2. 디자인 및 브랜드 컬러

- **컨셉**: '구름'이라는 느낌을 주기 위한 깔끔하고 부드러운 분위기.
- **브랜드 컬러**:
  - **White**: 배경 및 기본 컬러
  - **Sky Blue (Primary)**: `#00AEE` (포인트 컬러, 버튼, 하이라이팅 등)

## 4. 기술 스택 (Technology Stack)

현재 프로젝트(frontend)의 `package.json`을 기준으로 확정된 기술 스택입니다.

- **프레임워크**: Vue 3 (`vue: ^3.5.32`)
- **빌드 툴**: Vite (`vite: ^8.0.8`)
- **라우팅**: Vue Router (`vue-router: ^5.0.4`)
- **상태 관리**: Pinia (`pinia: ^3.0.4`)
- **스타일링**: TailwindCSS v4 (`@tailwindcss/vite`, `tailwindcss: ^4.3.0`)
- **HTTP 클라이언트**: Axios (`axios: ^1.16.1`)
- **언어**: TypeScript (`typescript: ~6.0.0`)
- **코드 퀄리티/포매팅**: ESLint, Prettier, Oxlint, Husky, Lint-staged
